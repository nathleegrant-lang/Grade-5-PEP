# Grade 5 PEP Practice 🇯🇲

This platform provides structured preparation for Grade 5 students 
getting ready for the Primary Exit Profile (PEP) examinations.

It focuses on strengthening skills through practice, revision, and 
mock assessments.

---

## 📚 Subjects Covered

- Mathematics
- Language Arts
- Science
- Social Studies

---

## ✨ Features

- Topic-based practice questions
- PEP-style assessments
- Mock examinations
- Answer explanations
- Student-friendly interface

---

## 🎯 Purpose

This platform helps students:
- Prepare for PEP exams effectively
- Practice key concepts regularly
- Improve confidence and performance

---

## 💡 Learning Approach

- Practice → Feedback → Improvement
- Structured progression across topics
- Encourages independent learning

---

## 👨‍👩‍👧 Who It’s For

- Grade 5 students preparing for PEP
- Parents guiding revision at home
